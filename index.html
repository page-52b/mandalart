3. Firestore Security Rules (보안 규칙 설정)

Firestore Database > Rules 탭에 다음 규칙을 작성하여 공유 링크(UID) 접속 시 읽기/쓰기가 가능하도록 허용하세요.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /mandalarts/{userId} {
      allow read, write: if request.auth != null;
    }
  }
}
